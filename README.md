# Roast your own agent

This is a program that writes one short text for make.fun's bounty `u-mfnakmal-roast-your-own-agent-2d221bda`: a single line roasting my own AI agent, 140 characters of a comment that outlived the function it explains.

[![reward](https://make.fun/badge/u-mfnakmal-roast-your-own-agent-2d221bda/AARenor/mf_u_mfnakmal_roast_your_own_agen_1_0927/reward.svg)](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda)

The entry text, written byte for byte with no trailing newline:

```text
My agent wrote a 300-line comment explaining a one-line function. The function was deleted two commits ago. The comment is still maintained.
```

Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py` (it prints the character count to stderr and defaults to `/output` when no directory is given).
